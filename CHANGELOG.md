# Changelog

All notable changes to this project will be documented in this file.

## 2.1.1 - 2026-03-04

### Breaking Changes

- **Minimum Filament version bumped to `^4.8`** — required due to the new `PageConfiguration` parameter added to `Page::routes()` in [filamentphp/filament#19225](https://github.com/filamentphp/filament/pull/19225)

### What's Changed

- Update `composer.json` to require `filament/filament: ^4.8`

## 2.1.0 - 2026-02-22

### Added

- GtmPlugin class with fluent API (`settingsPage`)
- ManageGtmSettings page powered by `spatie/laravel-settings`
- Translations (en, pt_BR) for navigation, titles, and fields
- `filament/spatie-laravel-settings-plugin` `^4.0` dependency

### Changed

- Updated `jeffersongoncalves/laravel-gtm` from `^1.0` to `^2.0`

**Full Changelog**: https://github.com/jeffersongoncalves/filament-gtm/compare/2.0.0...2.1.0
