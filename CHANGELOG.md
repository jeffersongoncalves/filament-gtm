# Changelog

All notable changes to this project will be documented in this file.

## 3.1.1 - 2026-03-04

### Breaking Changes

- **Minimum Filament version bumped to `^5.3`** — required due to the new `PageConfiguration` parameter added to `Page::routes()` in [filamentphp/filament#19225](https://github.com/filamentphp/filament/pull/19225)

### What's Changed

- Update `composer.json` to require `filament/filament: ^5.3`

## 3.0.1 - 2026-02-24

### What's Changed

- Add Laravel 13.x support (orchestra/testbench ^11.0)

## 3.1.0 - 2026-02-22

### Added

- GtmPlugin class with fluent API (`settingsPage`)
- ManageGtmSettings page powered by `spatie/laravel-settings`
- Translations (en, pt_BR) for navigation, titles, and fields
- `filament/spatie-laravel-settings-plugin` `^5.0` dependency

### Changed

- Updated `jeffersongoncalves/laravel-gtm` from `^1.0` to `^2.0`

**Full Changelog**: https://github.com/jeffersongoncalves/filament-gtm/compare/3.0.0...3.1.0
